# nVyR documentation

## Users

[User documentation](users/README.md) explains how to configure and operate nVyR:
commands, examples, defaults, troubleshooting, and recovery behavior.

Start with [using the CLI](users/cli.md), [installation](users/installation.md),
or the generated [command tree](users/command-tree.md).

## Developers

[Developer documentation](dev/README.md) explains how features are designed,
implemented, tested, packaged, and maintained.

Start with [architecture](dev/architecture.md), [adding features](dev/extending.md),
or [building with Docker](dev/debian.md).

Feature guides link to their implementation guides where a topic has both audiences.
Keep command usage in `users/` and implementation contracts and test procedures in
`dev/`; do not duplicate whole sections between them.
